# Lazy Polyglot

[English](README.md) · Русский · [O'zbekcha](README.uz.md) · [Приватность](docs/PRIVACY.md)

*Переведено с README.md (дата исходника: 2026-10-07). При расхождении основной считается английская версия.*

**Get (almost) accidentally fluent 🙂**  
*(Выучите язык почти случайно 🙂)*

Учите язык по ответам AI, которые вы и так читаете каждый день.

Lazy Polyglot вплетает слова изучаемого языка в ответы вашего AI-агента (Claude Code, OpenCode, Codex CLI, Antigravity CLI, Hermes Agent, OpenClaw и Gemini CLI в бете). Это техника *diglot weave*: вы работаете как обычно, а в ответах постепенно появляются слова на новом языке. Сначала 3–5 на ответ, потом чаще и сложнее, вплоть до правил словообразования, словосочетаний и простых конструкций. Никаких уроков. Погружение вместо зубрёжки.

> Вы: «помоги спланировать выходные в Барселоне»

> Агент: «Проведите **sábado** (субботу) в Готическом квартале: выходите **temprano** (рано), пока нет толпы, а вечером поужинайте у **mar** (моря).»

Из коробки 10 изучаемых языков. Подсказки (перевод в скобках) бывают на английском, русском или узбекском: на том из них, на котором вы пишете сообщение.

## Зачем я это сделал

Большая часть того, что я читаю каждый день, теперь ответы моих AI-агентов. Чтение на изучаемом языке — один из самых старых способов его выучить, поэтому мне захотелось, чтобы эти ответы попутно учили меня паре слов. Идея пришла из браузерных расширений вроде Toucan, которые делают то же самое с веб-страницами. Для AI-агентов такого не было, поэтому я сделал Lazy Polyglot для себя. Он бесплатен для всех, кому он тоже нужен.

## Как это работает

![День 1: новые слова приходят с переводом. Неделя 1: знакомые слова его теряют. Неделя 3: целые фразы.](docs/img/how-it-works.png)

- **Вы работаете как обычно.** Перед каждым ответом Lazy Polyglot незаметно подсказывает агенту несколько слов, и агент ставит их туда, где они к месту.
- **Новые слова приходят с переводом.** Через несколько ответов перевод уезжает в одну короткую строку в конце, а потом исчезает.
- **Слова возвращаются, когда вы вот-вот их забудете:** через 30 минут, потом через 8 часов, день, 4 дня, 2 недели и так далее. Считается только слово, которое ответ правда использовал.
- **Чем выше уровень, тем больше.** Сначала отдельные слова; с уровня 2 (он по умолчанию) ещё и то, как слова строятся (*-ция → -ción*); с уровня 4 короткие фразы, с 7 простые предложения. `/lazy-polyglot:level up` поднимает уровень.
- **Перевод на вашем языке:** английском, русском или узбекском, на каком вы пишете.
- **Всё остаётся на вашем компьютере.** Прогресс — небольшой файл в `~/.lazy-polyglot/`, никуда ничего не отправляется.

Техническая версия — в разделе [Под капотом](#под-капотом).

## Карточки и другие дополнения (Claude Code)

**Карточки.** Наберите `/cards`, и Lazy Polyglot проверит слова, которым пришёл срок, в обе стороны (испанский → русский, а позже русский → испанский). У карточек и вплетённых ответов один прогресс, так что слово, которое вы угадали в карточке, реже появляется в ответах.

![Квиз в /cards: карточка спрашивает ejemplo, вы пишете example, она проверяет ответ](docs/img/cards-quiz.gif)

Работает в терминале, во вкладке Code приложения Desktop, в VS Code и в мобильном приложении (macOS и Linux; Claude Code 2.1.287 или новее). В терминале карточка текстовая, в остальных местах выглядит как на анимации выше. Если в Desktop нет `/cards`, обновите приложение.

**Две маленькие опции, по желанию:**

- `/lazy-polyglot:cards-status on` показывает под полем ввода, приглушённо в конце строки подсказок, слово, которое ты учишь, и сколько слов уже выучено; с каждым сообщением слово новое: `? for shortcuts  ·  fiore = цветок  ·  5 of 451 learned`.
- `/lazy-polyglot:spinner on` показывает изучаемые слова, пока Claude думает. [Подробнее](#подсказки-в-спиннере-по-желанию).

## Не станут ли ответы агента хуже?

Всё устроено так, чтобы не стали. Инструкция запрещает трогать блоки кода, inline-код, идентификаторы, команды, пути, URL, цитаты и технические термины и прямо говорит модели, что смысл и качество ответа всегда важнее вплетения. Цена: одна короткая инструкция (≤600 токенов) на промпт, которая в основном читается из кэша промптов: около 1–3% от обычной сессии ([подробнее](docs/TokenUsage.md), на английском). Как с этим справляются четыре модели: [evals/MODELS.md](evals/MODELS.md), на английском. Если нужна чистая сессия, `/lazy-polyglot:pause` выключает вплетение сразу, а `/lazy-polyglot:resume` возвращает.

Плагин попадает в официальный каталог плагинов Anthropic, и новое имя быстрее понятно всем, кто встретит его там. Больше ничего не меняется. ## Быстрый старт

Проще всего попросить своего AI-агента (Claude Code, Codex, OpenCode, Antigravity, Hermes Agent, OpenClaw или другого). Вставьте ему:

```
Install Lazy Polyglot for me: https://github.com/shmsk/lazy-polyglot
```

Агент прочитает эту страницу и выполнит нужные шаги. Если какой-то шаг надо набрать вам самим (в Claude Code это две строки `/plugin` ниже), он скажет. Потом перезапустите сессию, и в ответах появятся испанские слова. Чтобы учить другой язык, скажите об этом агенту или наберите `/lazy-polyglot:lang` (например, `/lazy-polyglot:lang fr`).

**Понадобится** [bun](https://bun.sh) или Node.js 22.6 или новее (проверить: `bun -v` или `node -v`). Без них плагин остаётся выключенным, и Claude скажет об этом в начале сессии.

## Установка вручную

### Плагин Claude Code (рекомендуется)

```
/plugin marketplace add shmsk/lazy-polyglot
/plugin install lazy-polyglot@lazy-polyglot
# restart the session — replies start weaving Spanish (default: es, level 2)
```

Настройка не нужна: ни `npm install`, ни сборки, хук сам создаёт конфиг при первом запуске. Управление прямо из Claude Code: `/lazy-polyglot:status`, `/lazy-polyglot:lang pt`, `/lazy-polyglot:level up`, `/lazy-polyglot:mode 3`, `/lazy-polyglot:pause` / `/lazy-polyglot:resume`, `/lazy-polyglot:spinner on`, `/lazy-polyglot:placement`, а свой язык добавляется через `/lazy-polyglot:add-language <language>`.

**Карточки:** `/cards` открывает панель в терминале, во вкладке Code в Desktop, в VS Code и на телефоне. Она повторяет слова, которым пришёл срок, в обе стороны (изучаемый язык → ваш, а с 3-й ступени лестницы ещё и ваш → изучаемый), потом задаёт слова входного теста. Проверяет и записывает каждую карточку сам Lazy Polyglot, так что у карточек и вплетённых ответов один общий прогресс. macOS и Linux; входят в Lazy Polyglot с 0.9.1. Вне терминала каждая карточка рисуется как флеш-карточка (с 0.9.3). У каждого слова и ответа видны флаг и название языка (с 0.9.4). Нужен Claude Code 2.1.287 или новее; приложение Desktop держит свою копию Claude Code, так что если `/cards` там нет, обновите приложение.

**Подсказки на вашем языке:** перевод следует за языком вашего сообщения. Кириллица даёт русский; латиница даёт ваш `native`, если это `en` или `uz` (узбекский, латиница), иначе английский. `lazy-polyglot native <en|ru|uz>` (по умолчанию `en`) задаёт запасной язык для сообщения, которое Lazy Polyglot не может прочитать, а также язык ответов в квизе и подсказок в спиннере.

### Ручная установка хука

Для варианта с клоном нужен один `bun install` (только dev-зависимости; runtime-зависимостей у Lazy Polyglot нет).

```bash
git clone https://github.com/shmsk/lazy-polyglot && cd lazy-polyglot
bun install
bun src/cli.ts init                       # create ~/.lazy-polyglot
bun src/cli.ts install claude            # hook into the project's .claude/settings.json
# restart your Claude Code session — replies start weaving Spanish
```

Выберите один способ установки, а не оба. Если всё же совместите, защита от двойной доставки не даст счётчикам задвоиться. Интерактивный `quiz` работает в терминале: используйте ручной клон или вызовите CLI из кэша плагина (`~/.claude/plugins/cache/lazy-polyglot/…/scripts/cli.sh quiz`).

### Как плагин OpenCode

```
git clone https://github.com/shmsk/lazy-polyglot && cd lazy-polyglot
bun install
bun src/cli.ts install opencode           # project scope (.opencode/plugin/)
#   or:  bun src/cli.ts install opencode --scope user   # global (~/.config/opencode/plugin/)
# quit and restart OpenCode — replies start weaving Spanish
```

Одна команда ставит два пути, и оба работают одновременно:

- **Плагин (основной, надёжный)**: OpenCode находит его сам. Он цепляется к `experimental.chat.messages.transform`, запускает `lazy-polyglot hook` на вашем последнем сообщении и добавляет блок `<lazy-polyglot>` в контекст. Работает на любой модели.
- **Секция в AGENTS.md (запасной, экспериментальный)**: если плагины отключены или плагин не загрузился, модель получает указание сама запускать `lazy-polyglot hook` в начале каждого ответа. Зависит от того, слушается ли модель.

Защита от двойной доставки не даст счётчикам задвоиться, если оба пути сработают на один промпт.

### Как хук Codex CLI

```bash
git clone https://github.com/shmsk/lazy-polyglot && cd lazy-polyglot
bun install
bun src/cli.ts install codex --scope user   # ~/.codex/hooks.json (or --scope project: ./.codex/hooks.json)
# start codex, open /hooks and trust the lazy-polyglot hook — replies start weaving Spanish
```

Codex не запускает хуки, которые вы не одобрили, поэтому шаг с `/hooks` нужен один раз (и снова, если команда хука изменится). Хуку с `--scope project` нужно ещё, чтобы сам проект был доверенным. Если у вас стояла старая экспериментальная версия, установщик сам удалит её секцию из `AGENTS.md`. Сейчас Codex показывает вставленную инструкцию в переписке как видимое developer-сообщение ([openai/codex#16933](https://github.com/openai/codex/issues/16933)); это чисто косметика. Через Ollama (`ollama launch codex`) слова пока не вплетаются: Ollama теряет инструкцию, потому что игнорирует `developer`-сообщения не в начале разговора.

### Как плагин Antigravity CLI

```bash
git clone https://github.com/shmsk/lazy-polyglot && cd lazy-polyglot
bun install
bun src/cli.ts install antigravity --scope user   # ~/.gemini/config/plugins/lazy-polyglot (or --scope project: ./.agents/plugins/lazy-polyglot)
# start agy — replies start weaving Spanish
```

Плагин добавляет инструкцию перед каждым вызовом модели в ходе (`PreInvocation`) и читает ответ из транскрипта, когда ход закончен (`Stop`). Ещё он ставит короткое правило: сообщение `<lazy-polyglot>` приходит из вашего собственного плагина. Без него Gemini может принять это сообщение за prompt injection из только что прочитанного файла. `agy -p /hooks` должен показать два хука `lazy-polyglot`; `agy plugin disable lazy-polyglot` выключает плагин. Настройки работают и изнутри agy: `/lazy-polyglot:lang fr`, `/lazy-polyglot:level up`, `/lazy-polyglot:pause`, `/lazy-polyglot:status`, или просто попросите агента сменить язык.

### Как хук Gemini CLI (бета)

```bash
git clone https://github.com/shmsk/lazy-polyglot && cd lazy-polyglot
bun install
bun src/cli.ts install gemini --scope user   # ~/.gemini/settings.json (or --scope project: ./.gemini/settings.json)
```

Бета: адаптер написан по [справочнику хуков](https://github.com/google-gemini/gemini-cli/blob/main/docs/hooks/reference.md) Gemini CLI (`BeforeAgent` добавляет инструкцию, `AfterAgent` читает ответ обратно) и покрыт тестами, но на живом Gemini CLI его пока никто не запускал. Если у вас слова не вплетаются, пожалуйста, [заведите issue](https://github.com/shmsk/lazy-polyglot/issues). Перед запуском нового хука уровня проекта Gemini спрашивает разрешение: разрешите `lazy-polyglot`.

### Как плагин Hermes Agent

```bash
git clone https://github.com/shmsk/lazy-polyglot && cd lazy-polyglot
bun install
bun src/cli.ts install hermes           # $HERMES_HOME/plugins/lazy-polyglot/ (default ~/.hermes)
hermes plugins enable lazy-polyglot         # Hermes plugins are opt-in
# restart hermes — replies start weaving Spanish
```

Плагин — небольшой Python-файл, который через хук Hermes `pre_llm_call` передаёт каждый ход в CLI Lazy Polyglot, поэтому он одинаково работает и в CLI, и в мессенджерах вроде Telegram. Управлять им можно из любой сессии: `/lazy-polyglot status`, `/lazy-polyglot lang pt`, `/lazy-polyglot level up`, `/lazy-polyglot pause` / `/lazy-polyglot resume`. Ставить Python отдельно не нужно, хватит того, что уже идёт вместе с Hermes.

### Как плагин OpenClaw

```bash
git clone https://github.com/shmsk/lazy-polyglot && cd lazy-polyglot
bun install
bun src/cli.ts install openclaw         # generates the plugin in ~/.lazy-polyglot/openclaw-plugin/
openclaw plugins install --link ~/.lazy-polyglot/openclaw-plugin --force --accept-capabilities
openclaw config set plugins.entries.lazy-polyglot.hooks.allowConversationAccess true --strict-json
openclaw plugins enable lazy-polyglot
```

OpenClaw запускает хуки промпта только у тех плагинов, которым вы это разрешили, поэтому строка с `allowConversationAccess` обязательна. Плагин использует хук `before_prompt_build`, а `/lazy-polyglot status`, `/lazy-polyglot lang pt`, `/lazy-polyglot pause` работают в любом канале чата. Провайдер `claude-cli` в OpenClaw хуки промпта не запускает ([openclaw/openclaw#65157](https://github.com/openclaw/openclaw/issues/65157)); все остальные провайдеры запускают.

## Под капотом

Браузерные расширения (Toucan, Vocabo) переписывают DOM страницы. В CLI переписать ответ задним числом нельзя, поэтому Lazy Polyglot подкладывает короткую инструкцию через хук CLI, и вплетает слова сама модель. Ядро ничего не знает о конкретных CLI, адаптеры тонкие (архитектура вдохновлена [context-mode](https://github.com/mksglu/context-mode)).

```mermaid
flowchart LR
    A[You type a prompt] --> B[CLI hook runs<br/>lazy-polyglot hook]
    B --> C{Scan prompt<br/>for known words}
    C -->|recall found| D[Bump recall count<br/>in state.<lang>.json]
    C -->|no recall| E[Scheduler picks N<br/>least-seen words]
    D --> E
    E --> F[Build ≤600-token<br/>weave instruction]
    F --> G[Instruction injected<br/>into agent context]
    G --> H[Model weaves words<br/>into its reply]
    H --> I[After the reply: words it used<br/>climb the ladder in local state]
```

- **Словарь по концептам**: значения хранятся один раз в `data/concepts.json` (id, часть речи, tier, подсказки для каждого родного языка); каждый `data/wordlists/<lang>.json` — тонкая карта «концепт → лемма», так что новый язык — это один небольшой файл, а подсказки не расходятся
- **Словари**: ~400 базовых значимых слов на язык (существительные, глаголы, прилагательные, наречия) и 30 числительных, без служебных слов; по духу близко к базовым спискам вроде Сводеша. Новые слова идут от самых частых: порядок посчитан по частоте в субтитрах и новостях (источники в разделе «Частоты слов: источники»); поле tier оставляет место для уровня до 1000 слов, который открывается, когда база усвоена примерно на 80%
- **Прогресс по каждому языку**: состояние лежит в `~/.lazy-polyglot/state.<lang>.json` с ключом по id концепта, поэтому прогресс переживает исправления лемм и сравним между языками («вы знаете *солнце* в 3 языках из 5»)
- **Лесенка интервалов**: каждое слово возвращается через 30 минут, 8 часов, 1 день, 4 дня, 2 недели, 1 месяц, затем через 6 месяцев. На ступень вверх оно поднимается, только когда ответ действительно его использует, пока слово «созрело»; созревшие слова идут первыми, а четверть каждого списка остаётся свободной для новых слов
- **Честный подсчёт**: после ответа хук Stop (или событие хоста «после ответа») читает его обратно, и показанными считаются только те слова, которые ответ использовал. Хост без такого события, как и раньше, считает выданные слова
- **Переводы тают**: новое слово приходит как **casa** (house). Начиная с четвёртой ступени оно стоит просто как **casa**, а перевод даётся одной строкой в конце (`casa = house · nombre = name`). С пятой ступени (усвоено) перевода нет совсем, а усвоенные слова возвращаются как вращающаяся выборка, которую модель может использовать свободно, так что доля языка в ответах растёт
- **Только к месту, плюс подталкивание**: модель вплетает слово, только если ответу и так нужен его смысл, поэтому ничего не выдумывается ради слова. Единственное исключение: одно-два слова, которые всё время не попадали в ответы, можно вставить в короткое отступление или в заключительную строку, но никогда не в код, факты или текст, который вы скопируете
- **Сигнал вспоминания**: увидеть слово не значит его знать. Слово, которое вы использовали в своём промпте или правильно ответили в `quiz`, поднимается на ступень; неверный ответ в quiz возвращает его в начало, как и вопрос о его значении («что значит casa?», *what's casa?*), даже если слово уже считалось усвоенным. Слово, которое пишется так же, как английское (итальянские *via*, *fine*), засчитывается только вне английской фразы, а если вы ошиблись в слове или употребили его не в том значении, ответ поправит это одной строкой
- **Входной тест**: уже знаете часть языка? `lazy-polyglot placement` в терминале или `/lazy-polyglot:placement` в Claude Code спрашивает ещё не усвоенные слова из списка, самые частые первыми. Слово, переведённое верно, пропускает стадию нового и сразу попадает в усвоенные (повтор через две недели); незнакомое просто остаётся новым. Прогресс сохраняется после каждого слова, можно остановиться и продолжить позже. Lazy Polyglot предлагает тест один раз, когда вы начинаете язык, и снова, если вы пишете, что слова слишком простые
- **Режимы**: `lazy-polyglot mode 3` это всё описанное выше (по умолчанию). `mode 2` вплетает только те слова, которые подходят к месту, а `mode 1` просит использовать каждое слово из списка; оба засчитывают слово в момент выдачи
- **Уровни 1–10**: слова с 1-го уровня; [правила словообразования](#правила-словообразования) со 2-го (`data/patterns/<lang>.json`); словосочетания с 4-го и простые предложения с 7-го, на конструкциях из `data/grammar/<lang>.json`, если они есть у языка
- **Родной язык**: если вы учите свой родной язык (например, `en` при native `en`), подсказки берутся из другого языка

## Темы: слова для поездки или экзамена

Ядро учит ~450 повседневных слов, самые частые первыми. Тема ставит вперёд слова для одной цели: `/lazy-polyglot:topic рестораны в Барселоне к 20 ноября`, «тема к экзамену DELE A2», «переезжаю в Рим». Если цель размытая, агент задаст один-два вопроса, которые можно пропустить (какой город, примерно когда), и соберёт 40–150 слов и коротких фраз («la cuenta, por favor»). Слова, которые вы уже знаете, сохраняют свой прогресс.

- Слова темы идут первыми в ответах, `/cards` и placement до её даты или до `topic end`.
- `status` показывает каждую активную тему: `Topic Barcelona restaurants: 23/62 passed (18 words, 5 phrases) · 41 days left`.
- Не больше 20 новых записей в день: при сжатом сроке первые помещаются, остальные ждут, и вам об этом скажут.
- Две темы одновременно; третья спросит «вы уверены?», четвёртая подождёт, пока одна не закончится.
- Передумали: `topic end <имя>` останавливает тему, `topic delete <имя>` удаляет её совсем (после подтверждения). В обоих случаях выученное остаётся.

Как агент собирает тему: [docs/Topics.md](docs/Topics.md) (на английском).

## Вехи

Когда вы проходите 50, 100, 200, 300 или 400 усвоенных слов или всё ядро, агент заканчивает следующий ответ одной короткой строкой на изучаемом языке: к этому моменту вы её прочитаете. Половина темы, вся тема и неделя с новыми словами (раз в 7 дней) тоже получают строку.

- Не больше одной строки в день. Никаких серий и ничего о пропущенных днях.
- После обновления давно пройденные вехи не всплывают: счёт идёт от того места, где вы сейчас.
- `status` показывает путь до следующей: `Next milestone: ▓▓▓░░ 87/100`.
- `/lazy-polyglot:milestones off` выключает их вместе с полоской.

## Слова с несколькими значениями

Итальянское *carta* значит «бумага», но ещё и «карта» и «меню»; испанское *tiempo* значит и «время», и «погода». Во всех встроенных языках у слова записаны его частые другие значения, в `data/senses/<lang>.json`.

- Тест (placement), `/cards` и `quiz` засчитывают любое из них и говорят, какое ты назвал: `✓ carta: map is right too; main meaning paper (also: menu)`.
- Новое слово приходит только с главным значением. Когда оно станет знакомым, агент может употребить слово во втором значении, если ответу это нужно, всегда с переводом (**carta** (здесь: меню)) и никогда в двух значениях в одном ответе.
- [Тема](#темы-слова-для-поездки-или-экзамена) может попросить значение сразу: тема про поездку учит *carta* как меню.
- Учишь два языка, где одно написание значит разное (итальянское *carta* = бумага, испанское *carta* = письмо)? Новое слово один раз об этом скажет.
- Региональная версия убирает значение, которого там нет: испанское *piso* в Испании значит «квартира», а в Латинской Америке нет.

Переход на вариант не начинает обучение заново. У слов, которые пишутся одинаково, один общий прогресс: если вы учили испанский Испании и переключились на `es-419`, *casa* и все остальные слова остаются выученными, а учить нужно только 9 отличающихся. Они идут первыми, рядом с испанским словом: *carro = car, Spain: coche*. С грамматикой так же: сначала идут региональные конструкции (*ustedes trabajan*, а не *vosotros trabajáis*). Если слово базы в регионе варианта грубое, контраст об этом предупреждает: *tomar = to take, Spain: coger (vulgar in much of Latin America)*.

## Произношение

Французский, английский и португальский читаются не так, как пишутся, поэтому новые слова в них идут с произношением, буквами, которые вы уже читаете:

| Что вы видите | Настройка |
|---|---|
| **maison** (дом) | `off` |
| **maison** [мезо́н] (дом) | `native`, по умолчанию: русскими буквами, английской записью ([meh-ZAWN]) или узбекскими буквами ([mezon]), на языке, на котором вы пишете |
| **maison** [mɛzɔ̃] (дом) | `ipa`: международный фонетический алфавит |

Lazy Polyglot один раз спросит для каждого языка и покажет эти три варианта на слове из вашего списка; потом выбор меняет `/lazy-polyglot:reading off|native|ipa`. Произношение есть только у новых слов и уходит вместе с переводом. Его показывают и карточки, и подсказки в спиннере. Испанский, итальянский, немецкий и турецкий достаточно близки к написанию, у них произношения нет.

Произношение взято из Wiktionary в IPA, по одному на слово: у американского и британского английского, у европейского и бразильского португальского оно своё. Буквы получаются из IPA и передают звучание приблизительно, чтобы слово можно было прочитать вслух; точная форма это IPA. Добавить произношение к языку можно одним JSON-файлом, см. [docs/AddLanguage.md](docs/AddLanguage.md).

## Правила словообразования

Многие слова строятся одинаково в нескольких языках. *Революция* по-испански *revolución*, по-португальски *revolução*, по-итальянски *rivoluzione*, по-французски *révolution*. Выучите правило *-ция → -ción* один раз, и вы сможете читать сотни испанских слов, которые и так почти знаете. Так вплетение быстрее доходит до фраз.

- **Когда:** со 2-го уровня (он стоит по умолчанию) каждый ответ учит одно правило на примере: *-ция → -ción (revolución = революция)*.
- **За пределами списка слов:** ответ, который учит правилу, может использовать ещё одно слово по нему, даже если его нет среди ваших ~400.
- **С вашей стороны:** суффикс показывается на вашем родном языке. Русскоязычный видит *-ция → -ción*, англоязычный видит *-tion → -ción*. Некоторые правила есть только для одной стороны: *-ировать → -ieren* (*kopieren*) для русскоязычных, *-ly → -mente* для англоязычных.
- **Прогресс:** правило считается введённым после трёх ответов, после чего начинается следующее. `status` показывает это как *Word-building rules: 1/8 introduced*.
- **Ложные друзья:** правило предупреждает о словах, которые на него похожи, но значат другое, например *actual = текущий* рядом с *-al*. Значение дано на том языке, на котором вы пишете.
- **Где лежат данные:** правила в `data/patterns/<lang>.json`, ложные друзья и грубые слова в `data/falseFriends/<lang>.json`. Сколько правил у каждого языка, видно в таблице в разделе [Поддерживаемые языки](#поддерживаемые-языки). Каждое правило и пример сверены со словарём (в основном Wiktionary), а потом проверены второй моделью другого вендора.

## Числа

Любое число до 1000 строится из 30 слов: 0–20, десятки, 100 и 1000. Они стоят в вашем списке как обычные слова, не больше одного на ответ, и вплетаются рядом с цифрой, чтобы факт оставался читаемым: *деплой занял 3 (**tre**) минуты*.

- **Остальное через правила.** Когда в ответе есть числительное, Lazy Polyglot заодно показывает, как строятся числа побольше, по одному правилу за раз: *11–16 это готовые слова: undici, dodici… (e.g. 13 = tredici)*. После этого ответ может использовать число, построенное так, даже если его нет в списке.
- **У каждого языка своя логика.** В английском выучить 11 и 12, дальше *-teen*. Во французском 70 это *soixante-dix* (60+10), а 80 это *quatre-vingts* (4×20). В немецком единицы идут первыми: *einundzwanzig* (один-и-двадцать). В турецком десятки надо выучить, и узбекоязычные узнают несколько (*kırk*, *elli*).
- **Прогресс:** правило считается введённым после трёх ответов, потом место возвращается правилу словообразования. `status` показывает *Number rules: 2/7 introduced*.
- **Где лежат данные:** числительные в словарях, правила в `data/numbers/<lang>.json`, у каждого ссылка на страницу Wiktionary (все ссылки проверены), всё вычитано второй моделью.

Что менялось в каждой версии, есть в [CHANGELOG.md](CHANGELOG.md). После обновления `status` один раз показывает, что нового.

Что-то не так? Сначала проверьте, нет ли новой версии: возможно, это уже исправлено. Остальное в [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) (на английском). Спросите агента «почему Lazy Polyglot делает X», и он получит тот же совет.

| `instruction` | печатает инструкцию для модели (не засчитывая показы) |
| `hook` | режим хука CLI: перед ответом строит инструкцию и ищет в промпте вспомненные слова; после него (событие `Stop`) засчитывает слова, которые ответ использовал. При любой ошибке выходит с кодом 0, чтобы не ломать сессию хоста |
| `install claude [--scope project\|user]` | регистрирует хуки UserPromptSubmit, SessionStart и Stop |
| `install opencode [--scope project\|user]` | ставит плагин + запасную секцию в AGENTS.md для opencode |
| `install codex [--scope project\|user]` | регистрирует хуки UserPromptSubmit, SessionStart и Stop в `hooks.json` Codex CLI |
| `install antigravity [--scope project\|user]` | ставит плагин для Antigravity CLI (`agy`): хуки PreInvocation и Stop и одно правило |
| `install gemini [--scope project\|user]` | бета: регистрирует хуки BeforeAgent, SessionStart и AfterAgent в `settings.json` Gemini CLI |
| `install hermes` | ставит плагин Hermes Agent в `$HERMES_HOME/plugins/lazy-polyglot/` |
| `install openclaw` | генерирует плагин OpenClaw и печатает команды, которые подключают и включают его |

## Подсказки в спиннере (по желанию)

Пока Claude Code думает, его спиннер показывает подсказки. `/lazy-polyglot:spinner on` добавляет туда до 5 слов, которые вы сейчас учите (`Lazy Polyglot · frío = cold`), и обновляет их в начале каждой сессии. Это бесплатный бонус: подсказки в спиннере не засчитываются как показы.

Плагин не может поставлять подсказки спиннера сам, поэтому эта функция аккуратно пишет в ваш `~/.claude/settings.json`:

- **Выключено по умолчанию.** Установка Lazy Polyglot никогда не трогает ваши настройки.
- **Только наши строки.** Каждая добавленная подсказка начинается с `Lazy Polyglot · `; ваши подсказки, `excludeDefault` и все остальные ключи не трогаются. Если файл не валидный JSON, ничего не пишется.
- **Бэкап и атомарная запись.** Перед первым изменением исходный файл копируется в `~/.lazy-polyglot/settings.backup.json`.
- **Чистое выключение.** `/lazy-polyglot:spinner off` удаляет все строки с префиксом `Lazy Polyglot · `, а также ключ `spinnerTipsOverride`, если его создали мы.

## Перенос на другой компьютер

Прогресс хранится в `~/.lazy-polyglot/`, поэтому все CLI на одной машине уже видят общий. Чтобы перенести его на другой компьютер:

```bash
lazy-polyglot export                 # пишет ~/lazy-polyglot-export-YYYY-MM-DD.json
lazy-polyglot import ~/Downloads/lazy-polyglot-export-2026-10-01.json   # на другой машине
```

В чате то же самое: `/lazy-polyglot:export` и `/lazy-polyglot:import <файл>` (Claude Code) или `/lazy-polyglot export` и `/lazy-polyglot import <файл>` (Hermes, OpenClaw).

Импорт сливает, а не перезаписывает. Если вы уже начали тот же язык на другой машине, слова, которые есть только там, остаются, слова только из экспорта добавляются, а у слова, которое есть в обоих местах, остаётся лучшая запись: больше показов и вспоминаний, более высокая ступень лесенки повторений. Локальные настройки остаются, если не передать `--config`, а ваши словари и темы сохраняются, если отличаются. Перед любыми изменениями импорт копирует старые файлы в `~/.lazy-polyglot/backups/`. Повторный импорт того же файла или перенос обратно ничего не меняет.

Один компромисс: если одно и то же слово вы учили на обеих машинах, счётчики не складываются (5 и 10 дадут 10, а не 15). Если складывать, всё посчиталось бы дважды, как только файл съездит туда и обратно.

## Приватность

Хук работает локально. Он читает ваш промпт только чтобы найти в нём уже показанные слова (сигнал вспоминания). Промпт никогда не логируется, не отправляется по сети и нигде не хранится. На диск пишется только файл состояния для каждого языка в `~/.lazy-polyglot/` (читаемый JSON), который можно посмотреть, забэкапить или удалить через `rm -rf` в любой момент. У Lazy Polyglot нет сетевых обращений и нет телеметрии.

Когда ответ готов, хук ещё и читает его (хост передаёт его сам, либо он есть в локальном транскрипте Claude Code), чтобы засчитать только те слова, которые ответ действительно использовал. Слова, предложенные на текущий ход, до этого лежат в `~/.lazy-polyglot/served.json`. Сам ответ не сохраняется, и ничего не покидает ваш компьютер. `lazy-polyglot mode 1` или `mode 2` это отключает.

### Что запускается на вашем компьютере

- **Хуки** (Claude Code `UserPromptSubmit`, `SessionStart`, `Stop`): каждый запускает `scripts/hook.sh`, а тот запускает `bun` (или Node 22.6+) на `src/cli.ts hook`. На промпт хук добавляет в контекст инструкцию со словами, после ответа считает, какие слова ответ использовал. Читает и пишет только `~/.lazy-polyglot/`.
- **Мод `/cards`** запускает одну программу: `/bin/sh <plugin>/scripts/cli.sh cards …`, тот же CLI Lazy Polyglot, чтобы выбрать, проверить и сохранить карточки (`/bin/sh`, потому что `scripts/cli.sh` это shell-скрипт, который выбирает `bun` или Node). Чтобы найти этот скрипт, он читает переменные `LAZY_POLYGLOT_CLI`, `LANGCOUCH_CLI`, `HOME` и файл `~/.claude/plugins/installed_plugins.json`. Никуда ничего не отправляет и не ходит в сеть: программа, которую он запускает, локальная. Он добавляет одну команду, `/cards`, и его хук `command.run` отвечает только на неё: открывает панель с карточками.
- **Настройки Claude Code:** в `~/.claude/settings.json` пишет только `/lazy-polyglot:spinner on` (ваши слова как подсказки спиннера), а `off` удаляет ровно эти строки.
- **`/lazy-polyglot:add-language`** может писать только в `~/.lazy-polyglot/`.
- **Файлы, на которые можно не смотреть:** `evals/` — мой стенд, где я проверяю, как разные AI-модели вплетают слова. Он запускается только вручную мной, с моим ключом OpenRouter; плагин его никогда не запускает и ключ у вас не просит. `bunfig.toml`, `package.json` и `bun.lock` нужны для тестов и проверки типов, вам из них ничего не устанавливается.

## Удаление

- **Плагин Claude Code:** если вы включали спиннер, **сначала** выполните `/lazy-polyglot:spinner off` (у Claude Code нет хука удаления, так что плагин не может прибраться за собой сам). Затем `/plugin uninstall lazy-polyglot@lazy-polyglot` и перезапустите сессию. Уже удалили с включённым спиннером? Удалите строки, начинающиеся с `Lazy Polyglot · `, из `spinnerTipsOverride.tips` в `~/.claude/settings.json`.
- **Ручной хук Claude Code:** удалите записи `UserPromptSubmit`, `SessionStart` и `Stop`, команда которых заканчивается на `src/cli.ts hook`, из `.claude/settings.json` (или `~/.claude/settings.json`, если ставили с `--scope user`).
- **OpenCode:** удалите `lazy-polyglot.ts` из `.opencode/plugin/` (или `~/.config/opencode/plugin/`) и секцию между `<!-- lazy-polyglot:start -->` и `<!-- lazy-polyglot:end -->` в `AGENTS.md`.
- **Codex CLI:** удалите записи `UserPromptSubmit`, `SessionStart` и `Stop`, команда которых заканчивается на `src/cli.ts hook`, из `~/.codex/hooks.json` (или `.codex/hooks.json` для `--scope project`).
- **Antigravity CLI:** `agy plugin disable lazy-polyglot` или удалите `~/.gemini/config/plugins/lazy-polyglot/` (или `.agents/plugins/lazy-polyglot/` для `--scope project`).
- **Gemini CLI:** удалите записи `BeforeAgent`, `SessionStart` и `AfterAgent` с именем `lazy-polyglot` из `~/.gemini/settings.json` (или `.gemini/settings.json` для `--scope project`).
- **Hermes Agent:** `hermes plugins disable lazy-polyglot`, затем удалите `~/.hermes/plugins/lazy-polyglot/` (или каталог в вашем `$HERMES_HOME`).
- **OpenClaw:** `openclaw plugins uninstall lazy-polyglot`, затем удалите `~/.lazy-polyglot/openclaw-plugin/`.
- **Ваш прогресс:** `rm -rf ~/.lazy-polyglot` (не делайте этого, если можете вернуться: прогресс переживает переустановку).
